# Temirlan Rakhym — Multilingual Portfolio (`temirlan-about`)

Personal interactive "About Me" page built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS** in **4 languages (`RU | EN | KK | ZH`)** with a `Ctrl+K` / `⌘K` Command Palette.

## Features
- Instant 4-language switching (`RU`, `EN`, `KK`, `ZH`) synced with URL query (`?lang=`)
- Command Palette (`Ctrl+K` / `⌘K`) for section navigation, language switching, and quick contact copy
- Curated projects (`FunnelLens`, `Web Security Auditor`, `Telegram Audit Archiver`, `Decentrathon 6.0 QLoRA`)
- Verified education timeline & clickable certificate verification links
- Dedicated section on interests and engineering goals for **SkyWhisper & MonoLotus**

## Local Development

```bash
npm install
npm run dev
```
